# 顶会 Oral 论文的 Idea 发现模式库

> 用途：Agent A 提出 idea 前的学习材料。本库总结近年 NeurIPS / ICML / ICLR / ACL oral/spotlight
> 级别工作的「idea 是怎么被发现的」。状态以 OpenReview 为准，本库聚焦模式本身。
> 维护方式：读到值得学习的新 oral 论文，往对应小节追加即可。

## 一、oral 论文发现 idea 的六个共性模式

1. **把隐式假设变成可检验的问题**
   - 案例：DPO（NeurIPS 2023 oral）问「RLHF 必须用强化学习吗」→ 推导出奖励建模的闭式解，
     训练流程从两阶段砍成一步。发现方式：审视流行方法里「没人质疑过的那一步」。
2. **识别现有方法的结构性浪费，给出轻量替代**
   - 案例：QLoRA（NeurIPS 2023）问「微调 65B 真的需要 16bit 权重吗」→ NF4 量化 + 反传所需
     梯度只对低秩适配器，单卡可微调。发现方式：算清每一步的资源去向，找到最贵的那步。
3. **失败模式的系统化命名与分解**
   - 案例：Tree of Thoughts / ReAct 系列把「LLM 单步推理会错」分解为可回溯、可分支、可纠错的
       显式过程。发现方式：收集失败案例，找出共性失败维度，把「改进提示词」升级为「改进过程结构」。
4. **评测空隙 = 顶会机会**
   - 案例：LongMemEval（ICLR 2025）发现「长程记忆没有严谨基准」→ 构建可度量、可分能力的
     评测集，顺带实证指出主流方法的系统性缺陷。发现方式：survey 时记录「大家都在说好但没人量过」的能力。
5. **跨领域机制borrowing必须算法化**
   - 案例：HippoRAG（NeurIPS 2024）借海马体索引理论，但贡献不是比喻而是「Personalized PageRank
     上的具体检索算法」。发现方式：跨领域灵感必须翻译成算法等价物，隐喻不能进方法节。
6. **简单规律的可扩展性报告**
   - 案例：各类 scaling/涌现分析论文，把社区口口相传的经验变成可预测的定量规律。
     发现方式：控制变量跑小网格，画出别人没画过的曲线。

## 二、分方向代表作（问题 → 机制 → 验证）

### LLM Agent 与记忆
- **MemGPT**（ICLR 2024）：上下文有限但对话无限 → 虚拟内存分页式记忆管理 → 多档长对话任务 +
  文档分析，对比固定上下文基线。
- **HippoRAG**（NeurIPS 2024）：RAG 在多跳问题上把长文当孤立块 → 海马体索引理论算法化为
  LLM抽取实体图 + Personalized PageRank → MuSiQue/2Wiki 上单跳检索大幅提升且成本远低于微调。
- **LongMemEval**（ICLR 2025）：长程记忆能力无严谨评测 → 五能力分解的可扩展基准 → 实证指出
  商用助手记忆能力的系统性短板。

### 推理与对齐
- **Chain-of-Thought**（NeurIPS 2022）：大模型直接答错 → 把答案生成改为中间步骤显式化 →
  算术/常识/符号三类任务的规模拐点分析。
- **DPO**（NeurIPS 2023 oral）：RLHF 两阶段贵且不稳 → 奖励函数可解析消去的闭式目标 →
  与 PPO 级别对齐效果的直接对比。
- **Toolformer**（NeurIPS 2023）：LLM 不会用工具且标注稀缺 → 自监督「在哪插 API 调用能降低
  困惑度」自动标注 → 保留语言能力的同时学会工具调用。

### 训练效率
- **QLoRA**（NeurIPS 2023）：微调大模型显存爆炸 → 4-bit NormalFloat + 双重量化 + 分页优化器 →
  Guanaco 65B 单卡 48h，基准追平 GPT-3.5。
- **LoRA**（ICLR 2022）：全参微调贵且部署多副本难 → 冻结权重+低秩旁路，推理时零额外延迟 →
  多任务部署与容量对比分析。

### 从底层出发的代表（2026，重点对标）
- **Context Language Models / CLM**（arXiv 2609.37725，Rulin Shao, Luke Zettlemoyer, Mike Lewis,
  Nathan Lambert 等）：Agent 上下文管理全靠外部框架打补丁 → 一个抽象解决：**把上下文当文件，
  模型原生自由编辑**（写入/删除/改写自己决定），零样本即可用现有模型实现 → BrowseComp-Plus
  准确率 +11.4% 且 FLOPs -21.5%，12小时任务 FLOPs -59%，多智能体场景=多个上下文文件共存；
  配套技能优化循环（held-out 任务最高 +35.9 点）、在线 RL、服务端 Suffix Cache Reuse（同性能
  省 35% 算力）。**模式提炼：找到领域里"所有人都用外部框架打补丁"的那一层，把补丁移进模型
  本体，一个抽象替代一整个生态的 hack。**

## 三、给你的提示（Agent A 必读）

提出 idea 前自问三个问题：
1. 我瞄准的「隐式假设 / 结构性浪费 / 评测空隙」具体是哪一个？在哪个代表工作上有据可查？
2. 我的机制把灵感（如果有）算法化了吗？去掉灵感来源的名词后机制是否仍然完整？
3. 我的验证设计能让审稿人 5 分钟内看懂「赢了谁、赢了多少、为什么可信」吗？
